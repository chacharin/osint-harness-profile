# Sub-skill 2: Source_Evaluation
(การประเมินความน่าเชื่อถือและวาระซ่อนเร้น)

## When to Use
- เมื่อผู้บังคับบัญชาสั่ง "ต่อไป" หรือ "next" หลังรายงานขั้นที่ 1 (ขั้นที่ 2 ของ Pipeline ใน intelligence-analyzer)
- เมื่อผู้บังคับบัญชาสั่งแก้ผลของขั้นที่ 2 ก่อนสั่ง "ต่อไป"

**หน้าที่:** ตรวจสอบและประเมินคุณภาพของแหล่งที่มา เพื่อป้องกันการนำข้อมูลที่มีอคติมาใช้ตัดสินใจระดับบริหาร

## Procedure

### 1) เปิดแฟ้มงานเดิม
1. ใช้แฟ้มงานเดิมของภารกิจตามข้อ 6.3 ของ intelligence-analyzer
2. อ่าน `<แฟ้มงาน>/step1.md` ด้วย `read_file` และตรวจว่าบรรทัดแรกตรงกับชื่อแฟ้มงาน หากไม่มีไฟล์ ให้หยุดและแจ้งผู้บังคับบัญชา

### 2) ความน่าเชื่อถือของแหล่ง (Reliability)
จัดประเภทแหล่งทุกแหล่งในทะเบียน:

| ประเภท | ตัวอย่าง |
|---|---|
| หน่วยงานรัฐ (Official) | กระทรวง หน่วยงานรัฐบาล องค์การระหว่างประเทศ |
| สถาบันวิจัย (Think Tank) / วิชาการ | สถาบันคลังสมอง มหาวิทยาลัย วารสารวิชาการ |
| สื่อกระแสหลักที่น่าเชื่อถือ | สำนักข่าวที่มีกองบรรณาธิการและมาตรฐานการแก้ข่าว |
| สื่อที่รัฐให้การสนับสนุน (State-affiliated) | สื่อที่รัฐเป็นเจ้าของหรือให้ทุน |
| ภาคเอกชน/บริษัท | รายงานบริษัท สมาคมอุตสาหกรรม |
| บล็อกเกอร์อิสระ / โซเชียลมีเดีย | บุคคล บัญชีโซเชียล เว็บไซต์ที่ไม่มีกองบรรณาธิการ |

แล้วให้ระดับความน่าเชื่อถือ **สูง / ปานกลาง / ต่ำ** พร้อมเหตุผลสั้น ๆ

### 3) ความถูกต้องของข้อมูล (Credibility)
1. ไล่ตรวจข้อเท็จจริงทุกข้อ (FACT 1, FACT 2, …) ใน `step1.md`
2. ใช้ `perplexity_search` หรือ `perplexity_ask` หาแหล่งอื่นที่มีจุดยืนต่างกันมายืนยันหรือโต้แย้ง (Cross-reference)
3. แหล่งใหม่ที่พบให้ขึ้นทะเบียนต่อเลขเดิม (เช่น หาก `step1.md` จบที่ `[SOURCE 12]` ให้เริ่ม `[SOURCE 13]`) ไว้ในหัวข้อ "ทะเบียนแหล่งเพิ่มเติม" ของ `step2.md` **ห้ามแก้ไข `step1.md`**
4. ให้สถานะข้อเท็จจริงแต่ละข้อเป็นหนึ่งในสามแบบนี้:
   - `ยืนยันข้ามแหล่งแล้ว [ประกอบด้วย SOURCE x; SOURCE y; และ SOURCE z]` — มีแหล่งอิสระต่อกันอย่างน้อย 2 แหล่งยืนยันตรงกัน
   - `แหล่งเดียว [SOURCE x]` — ยังไม่พบแหล่งอื่นยืนยัน
   - `ขัดแย้ง [ระหว่าง SOURCE x และ SOURCE y]` — แหล่งให้ข้อมูลไม่ตรงกัน พร้อมระบุว่าขัดแย้งตรงไหน

### 4) อคติและวาระซ่อนเร้น (Bias & Agenda)
สำหรับแต่ละแหล่ง ประเมินว่ามีผลประโยชน์ทับซ้อนทางการเมือง เศรษฐกิจ หรืออุตสาหกรรมหรือไม่ (เช่น สื่อที่ได้รับการสนับสนุนจากรัฐ หรือรายงานจากบริษัทที่มีส่วนได้ส่วนเสีย) โดยพิจารณาเจ้าของ แหล่งทุน และผลประโยชน์ที่ได้จากการนำเสนอ แล้วให้ระดับอคติ **ต่ำ / ปานกลาง / สูง** พร้อมเหตุผล

### 5) ข้อควรระวังในการใช้ข้อมูล
สรุปข้อเท็จจริงที่ต้องใช้อย่างระมัดระวัง ได้แก่ ข้อที่มีสถานะ `แหล่งเดียว` หรือ `ขัดแย้ง` และข้อที่อาศัยเพียงแหล่งที่มีความน่าเชื่อถือต่ำหรืออคติสูง

### 6) เขียนไฟล์และรายงาน
1. เขียน `<แฟ้มงาน>/step2.md` ด้วย `write_file` ตามแบบฟอร์มด้านล่าง
2. ตรวจคำสะกดด้วย `proofread_thai` กับไฟล์ `step2.md`
3. รายงานผลตามรูปแบบในข้อ 8 ของ intelligence-analyzer โดยแสดงเนื้อหา `step2.md` ฉบับเต็ม และปิดท้ายตามข้อ 4 ของ intelligence-analyzer

## Pitfalls
- **นับแหล่งที่ลอกกันมาเป็นการยืนยัน:** หลายสำนักข่าวที่อ้างแหล่งต้นทางเดียวกัน (เช่น อ้างแถลงการณ์ฉบับเดียว) ไม่ถือเป็นการยืนยันข้ามแหล่ง
- **ตัดสินจากชื่อเสียงอย่างเดียว:** แหล่งน่าเชื่อถือสูงก็อาจมีอคติในบางประเด็น ต้องประเมินสองมิติแยกกัน
- **แก้ไขไฟล์ขั้นก่อนหน้า:** ห้ามแก้ `step1.md` แหล่งใหม่ให้อยู่ใน `step2.md` เท่านั้น
